# Мой пет-проект

Идея: Telegram-бот для учёта личных расходов. Пользователь отправляет сумму и категорию расхода, а бот сохраняет данные и показывает статистику.

Стек: Python, Telegram Bot API, SQLite, Git, Linux/Git Bash.

Цель: научиться создавать небольшое приложение с нуля, работать с API, базой данных и логами, а также уверенно использовать Git Bash и команды Linux.

Сроки реализации: 1 месяц
