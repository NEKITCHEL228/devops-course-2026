# Мои заметки о VS Code и Git

1. Удобно видеть изменённые файлы и просматривать изменения прямо в VS Code.
2. Удобно делать commit через встроенный интерфейс Git.
3. Удобно просматривать историю изменений и переключаться между ветками.

В терминале удобнее выполнять команды Git, особенно когда нужно быстро работать с несколькими командами подряд.
