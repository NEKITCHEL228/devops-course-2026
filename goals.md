# Мои цели на семестр по курсу DevOps

1. **Освоить контейнеризацию с помощью Docker**: научиться писать эффективные `Dockerfile`, создавать многоконтейнерные приложения с `docker-compose` и оптимизировать вес образов.
2. **Настроить полноценный CI/CD-пайплайн**: автоматизировать тестирование, сборку и развертывание учебного проекта с использованием GitHub Actions.
3. **Уверенно работать с командной строкой Linux и Git**: освоить базовое администрирование системы (Bash-скрипты, systemd, сеть) и командные стратегии ветвления (GitFlow).
